# ReduxFlakes

Hi, I'm ReduxFlakes, a software developer & designer from Portugal.

Most of my work consist of Windows software development through .NET, C#, and WPF where I'm currently developing [Celer](https://github.com/surfscape/celer). I also do web, if it's static websites then [11ty](https://www.11ty.dev/), and for web apps [Svelte](https://svelte.dev/). I did Android app development years ago and have used both Android Views and Jetpack Compose.
